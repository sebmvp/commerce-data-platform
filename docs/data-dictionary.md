# Data Dictionary — synthetic sample data

All values in `sample_data/` are 100% synthetic and generated by
`sample_data/generate_sample_data.py` (seeded `random` for reproducibility).

## channels.jsonl

Three rows: two versions of the same Grailed storefront (fee change
Jan 1 2026 → SCD-2) and one Depop storefront.

| Field | Type | Notes |
|---|---|---|
| `platform` | string | grailed / depop |
| `handle` | string | storefront handle |
| `standing` | enum | active / suspended / closed |
| `fee_pct` | float | platform fee fraction |
| `valid_from` | timestamp | when this version became active |

## catalog_items.jsonl

Twelve items across sneakers/streetwear categories.

| Field | Type | Notes |
|---|---|---|
| `sku` | string | natural key: `product-size` |
| `product` | string | display name |
| `variant` | string | colorway |
| `size` | string | unisex sizing as string (US men's) |
| `acquisition_cost_cny` | float | CNY basis (typical source market) |
| `status` | enum | planned → in_transit → owned → listed → sold |
| `target_price_usd` | float | asking price |

## item_events.jsonl

Event-sourced lifecycle per item. Events only append.
- `ordered` → `received` → `listed` → `sold`

## listings.jsonl

One row per (item × platform) listing. `sold` rows include `sold_at` /
`sold_price_usd`.

## engagement_metrics.jsonl

Daily per-listing snapshots: `views`, `watchers`, `offers`. Roughly
log-decay by recency with 10–20% daily watch rate — synthetic but shaped
to match observed public patterns on Grailed.

## orders.jsonl

One row per sold listing with fee calculation platform-specific
(Grailed 9%, Depop 10%).

## content_pieces.jsonl

Published listing-content copies with `tone` / `cta` metadata. Tones are
distribution-weighted to favor `storyteller` — see `docs/assumptions.md`.

## content_snapshots.jsonl

48-hour post-publish performance snapshots feeding
`insights.voice_profile`. `TONE_WEIGHTS` in the generator creates the
separation between conversion styles.
